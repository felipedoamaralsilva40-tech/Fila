Descrição do Projeto

Este projeto consiste em um sistema de fila de senhas desenvolvido em Python. O sistema utiliza Autômatos Finitos Determinísticos (AFDs) para validar senhas e guichês, além de um scanner léxico para reconhecer comandos e identificar erros.

Funcionalidades

Validação de senhas preferenciais e normais.

Validação de guichês de atendimento.

Representação gráfica dos AFDs.

Tabelas de transições dos autômatos.

Testes dos validadores.

Scanner léxico com testes de Maximal Munch.

Interface interativa para realizar validações e analisar comandos.

Python

Jupyter Notebook

Expressões regulares (re)
